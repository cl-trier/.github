## 🔬 Research Repositories

Below you’ll find an overview of research-related repositories, grouped by project.

---

### CLTrier Lib – Utility Library

A Python library providing structured utility modules for NLP workflows, including classification, inference schemas, and pipeline orchestration.

**Repository**: 
- [`cltrier_lib`](https://github.com/cl-trier/cltrier_lib)

---

### CLTrier NLP – Teaching Toolbox

A modular Python package built for teaching NLP methods at Trier University.
**Repository**: 
- [`cltrier_nlp`](https://github.com/cl-trier/cltrier_nlp)

---

### CLTrier PromptClassify – Zero‑Shot Prompt-Based Classification

An experimental framework for zero‑shot classification using prompt-based approaches on foundation models, applied e.g. to topic labeling of German tweets.

**Repository**: 
- [`cltrier_promptClassify`](https://github.com/cl-trier/cltrier_promptClassify)


---

### CLTrier ProSem – Probing & Classifying Semantic Spans

A Python-based pipeline for probing and classifying semantic spans in text data.

**Repository**: 
- [`cltrier_prosem`](https://github.com/cl-trier/cltrier_prosem)

---

### TWON – Twin of an Online Social Network

TWON is an EU-funded research initiative building a digital twin of online social networks using generative AI to analyze how platform design and algorithms impact polarization, misinformation, and democratic debate.


**Repositories**:
- [`TWON-Agents`](https://github.com/cl-trier/TWON-Agents)
- [`TWON-Evaluation`](https://github.com/cl-trier/TWON-Evaluation)
- [`TWON-Exploration`](https://github.com/cl-trier/TWON-Exploration)
- [`TWON-Metrics`](https://github.com/cl-trier/TWON-Metrics)
- [`TWON-Ranker`](https://github.com/cl-trier/TWON-Ranker)
